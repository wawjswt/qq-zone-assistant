# QQ 空间相册下载

一个用于批量保存 QQ 空间普通相册的浏览器扩展。打开相册后，即可将照片打包下载，并尽量保留照片的时间和原有元数据。

**批量下载** · **自动命名** · **保留照片信息**

---

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 批量下载 | 分页获取相册照片并打包为 ZIP，默认下载全部照片；填写数量可限制下载上限 |
| 自动命名 | ZIP 使用相册名称；文件名中的非法字符会替换为 `-` |
| 防止同名覆盖 | 图片按顺序添加唯一序号，例如 `0001_照片.jpg`、`0002_照片.jpg` |
| 保留图片格式 | 根据图片实际格式使用相应的文件扩展名 |
| 保留时间与元数据 | 优先使用照片原始时间，并保留原有相机信息；详见下方说明 |
| 下载进度 | 弹窗中显示当前相册名称和下载进度 |

> 目前支持 QQ 空间的**普通相册**；旅游相册使用不同接口，暂不支持。

## 安装

1. 将本仓库下载到电脑并解压，或通过 Git 克隆。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的项目文件夹。

更新项目文件后，需要在扩展管理页面点击该扩展的**重新加载**按钮。

## 下载相册

1. 登录 [QQ 空间](https://qzone.qq.com/)，打开要下载的具体相册。
2. 点击浏览器工具栏中的 **QQ 相册下载** 图标。
3. 按需设置最大下载数量；默认留空并下载全部，填写数字可限制数量。
4. 点击 **下载相册**，等待照片下载和 ZIP 打包完成。
5. 按浏览器的下载设置保存 ZIP。文件名会自动使用相册名称。

建议下载期间保持扩展弹窗打开。浏览器如果开启了“下载前询问每个文件的保存位置”，仍会弹出保存窗口，文件名会自动填好。

## 照片时间与元数据

每张照片单独选择时间，依次尝试：

1. 图片 EXIF 原始拍摄时间（`DateTimeOriginal`）
2. 图片数字化时间（`CreateDate`）
3. 图片元数据修改时间（`ModifyDate`）
4. 相册接口返回的拍摄时间（`rawshoottime`、`shootTime` 或 `shoottime`）
5. QQ 空间上传时间

缺失或无效的时间会被跳过。选中的时间写入 ZIP 文件时间，解压后可在资源管理器的 **修改日期** 中查看；如果以上时间都不可用，文件时间使用打包时间。ZIP 文件时间的精度为 2 秒。

JPEG 和 PNG 还会在图片内部记录以下字段：

| 字段 | 内容 |
| --- | --- |
| `QZonePhotoTime` | 根据上述优先级选中的时间 |
| `QZoneTimeSource` | 选中时间的来源 |
| `QZoneUploadTime` | QQ 空间的实际上传时间，如有提供 |

JPEG 使用内部备注，PNG 使用文本字段。图片不会重新压缩，原有 EXIF、拍摄日期和相机信息会保留；资源管理器不一定直接显示这些新增字段。未提供时区的 EXIF 时间保留原始钟面时间；接口仅提供日期时，ZIP 文件时间使用当天 00:00:00。

WebP、GIF 等其他格式保留原图，时间信息写入同名 `.metadata.json` 文件，请与图片一同保存。只能保留实际下载到的图片中已有的元数据。

## 常见问题

**提示没有获取到相册地址？** 先登录 QQ 空间，打开具体相册，然后重新点击扩展。必要时刷新相册页面后再试。

**为什么下载到的照片比相册数量少？** 检查弹窗中的最大下载数量；留空可请求全部照片。网络错误或相册接口变化也可能影响下载。

**为什么创建日期是解压时间？** ZIP 保存的是文件修改时间，本地创建日期通常由解压过程产生。请查看资源管理器中的“修改日期”。

**为什么部分照片旁边有 `.metadata.json`？** 这些图片的格式暂不支持写入内部时间字段，信息保存在同名文件中；下载完成时会提示数量。

## 项目结构

```text
├── manifest.json             扩展配置
├── src/
│   ├── background.js         捕获相册列表请求
│   ├── popup.html            弹窗界面
│   ├── popup.js              相册分页、交互和下载
│   ├── styles.css            弹窗样式
│   ├── photoDownloader.js    图片下载、时间处理和 ZIP 打包
│   ├── jszip.min.js          ZIP 打包库
│   └── vendor/               EXIF 读取库及其许可
└── tests/                    自动化测试和测试图片
```

项目无需构建。安装 Node.js 后，可在项目目录运行测试：

```sh
node --test tests/*.test.cjs
```
