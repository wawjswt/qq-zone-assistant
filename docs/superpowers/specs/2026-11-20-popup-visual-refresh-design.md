# QQ 相册下载弹窗视觉改版

## 目标

让弹窗更像一个清晰、轻巧的相册工具：当前相册、数量设置、主要下载操作与下载状态一眼可辨。保留既有下载逻辑和流程，只调整界面表达。

## 方案比较

- **A：蓝色封面式（本次采用）**：大面积 QQ 蓝与黄色主按钮，品牌感强、识别度高。通过紧凑分区控制视觉重量；使用相册图标和装饰性照片边框表达主题，不伪造实际照片缩略图。
- **B：照片索引式**：白色底层、清晰分区、照片主题的视觉标记，以 QQ 蓝作为操作色、暖黄作为小面积强调。层级轻快，适合扩展弹窗的有限宽度。
- **A/B 混合**：保留封面式大色块并加入照片索引；信息层次会比当前强，但在小窗口里更容易拥挤。

用户选择了“先集中重做界面外观”、查看两张草图并选择 A；用户已确认按此设计改弹窗。

## 设计与边界

- 用相册封面与照片边框的视觉语言表达照片下载场景。
- 保留当前数量输入、开始下载、进度、完成与错误状态；不新增下载历史、取消操作或缩略图获取。
- 使用 QQ 蓝色主面板、暖黄色主按钮、紧凑卡片分区和清晰字号层级；不使用远程图片或外部字体。
- 保持键盘焦点可见，并尊重系统的减少动态效果设置。

## 验收方式

在扩展弹窗中对比现有界面，检查默认态、下载状态、完成态、警告/错误态的层级和可读性；确认不改动下载逻辑。
